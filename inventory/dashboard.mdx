# Inventory Management

The **Inventory Management** page shows current stock for every SKU at every warehouse. From here you inspect positions, see their value, upload inventory, review history, count stock, and propose or approve on-hand adjustments.

## Page tabs

Where: sidebar → **Inventory** → **Dashboard**.

| Tab | Purpose | Who sees it |
|-----|---------|-------------|
| **Inventory** | Current stock across warehouses | Everyone with inventory access |
| **History** | The inventory change feed and point-in-time snapshots | Everyone with inventory access |
| **Counts** | Physical counts (cycle counts) | Orgs on Tether's movement ledger, for users who can adjust or approve inventory |
| **Approvals** | Adjustment requests waiting for a decision | `inventory:approve` |
| **My requests** | Your own adjustment requests and their outcomes | `inventory:adjust` |

See [Inventory history](/inventory/history), [Inventory counts](/inventory/counts) and [Inventory adjustments](/inventory/adjustments).

## Status cards

Where: **Inventory** → **Dashboard** → **Inventory** tab, above the grid.

The cards count positions by health: **Out of Stock**, **Low Inventory**, **Healthy**, **Overstock**, and **No status** (shown only when some positions have no verdict). Click a card to filter the grid to it; click **No status** to see why those positions weren't judged. See [How runout and coverage status work](/inventory/coverage-and-runout).

## How do I see one row per SKU across warehouses?

Where: **Inventory** → **Dashboard** → **Inventory** tab → toolbar → **One row per SKU**.

**One row per SKU** folds the grid into a single row per SKU with a column group per warehouse. Click it again to go back to one row per SKU and warehouse. Warehouse and health status grouping are unavailable while it's on, since those values belong to each position.

## How do I see inventory value in dollars?

Where: **Inventory** → **Dashboard** → **Inventory** tab → toolbar → **Show value**.

Click **Show value** (it then reads **Showing value**). Quantity cells switch to dollars, and a summary bar above the grid shows **Inventory cost**: what the rows on screen are worth **at current Default cost** (each SKU's Default cost × on hand). Filters and search change the total.

If some SKUs have no Default cost, the bar says "N SKUs have no Default cost — total understated". Click it to filter to those SKUs, then set their Default cost on the SKU's **Cost & price** tab.

### Why does the on-hand value say unavailable?

Where: **Inventory** → **Dashboard** → **Inventory** tab → **Show value** → the summary bar.

"Inventory cost unavailable — no Default cost is set for the SKUs in view" means none of the SKUs on screen has a Default cost, so there is nothing to multiply by. Set a Default cost on those SKUs (**Products** → **SKUs** → a SKU → **Cost & price**) or widen your filters.

## How do I add consumption columns to the inventory page?

Where: **Inventory** → **Dashboard** → **Inventory** tab → **Table Settings** → **Display metrics**.

Pick one or more time windows. Each window adds three columns: what the location consumes itself, what it ships onward, and its whole draw. Save with nothing selected to remove them. The button shows how many windows are on, for example **Display metrics (2)**.

## Filtering, grouping and exporting

Where: **Inventory** → **Dashboard** → **Inventory** tab → toolbar.

- **Search inventory…** matches SKU code and name.
- Filters include warehouse (your org's word for it, for example Location), location group, collection or SKU group, SKU, SKU type and product attributes.
- **Table Settings** → **Grouping** opens **Configure Grouping**, where you pick and order the levels rows are grouped by.
- **Show Units** / **Hide Units** shows or hides the unit of measure next to quantities.
- **Table Settings** → **Export to CSV** downloads the grid as filtered. Table Settings also has density, hide zeros and show all filters.
- Saved **Views** keep a combination of filters and columns.

## How do I edit several on-hand quantities at once?

Where: **Inventory** → **Dashboard** → **Inventory** tab → **Table Settings** → **Edit quantities**.

Turn on **Edit quantities** ("Type counts into On Hand and submit them together"), type the counted figures into the **On Hand** cells across any SKUs and warehouses, pick a reason in **Select reason for adjustment**, and click **Save Changes**. Whether each change applies at once or waits for approval follows the normal [adjustment approval flow](/inventory/adjustments). Turning the toggle off discards what you typed. You need `inventory:adjust` to see the toggle.

For a full shelf count with expected vs counted, use [Counts](/inventory/counts) instead.

## Right-click actions

Where: **Inventory** → **Dashboard** → **Inventory** tab → right-click a row (or, with **One row per SKU**, a warehouse's cell).

- **Adjust on-hand…**: propose a change to the position's on-hand. See [Inventory adjustments](/inventory/adjustments).
- **Committed details & holds**: what makes up the committed quantity and what is held.
- **Assign unassigned stock to a lot…**: shown for lot-tracked SKUs with stock not yet in a lot. See [Lots](/inventory/lots#how-do-i-assign-stock-to-a-lot).
- **Remove from warehouse**: zero out a position through an audited adjustment.

With **One row per SKU** on, each action applies to the warehouse of the cell you clicked and its label names that warehouse.

## Uploading inventory

Where: **Inventory** → **Dashboard** → **Upload Inventory** (top right).

Users with a write permission see **Upload Inventory**. An upload is treated as a batch of inventory adjustments; check the [History tab](/inventory/history) afterwards to confirm it applied. The button is hidden for users without write permission and on the counting view.

## Troubleshooting

### Approvals, My requests or Counts tab is missing

Approvals needs `inventory:approve` and My requests needs `inventory:adjust`. Counts also needs your org to be on the movement ledger. See [Roles & Permissions](/roles-permissions) and [Why don't I see the Counts tab?](/inventory/counts#why-dont-i-see-the-counts-tab).

### A count looks wrong

A pending adjustment may not be approved yet, or an integration sync may be in flight. Check **Approvals** for a pending request, then open **History** and click the position to see every change with its source.
