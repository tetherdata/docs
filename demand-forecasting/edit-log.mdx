# Edit Log

The Edit Log lists every saved forecast edit from the [Demand Dashboard](/demand-forecasting/dashboard): one row per save, with who saved it, why, which SKUs and channels it touched, and its impact on units and revenue.

## Where is the forecast edit log?

Where: **Demand** → **Edit Log** in the sidebar (`/demand-forecast/edit-log`). The page title is **Forecast Edit Log**.

**Settings** → **Forecast Edit Log** is a different page: it holds the logging settings, not the log (see [below](#how-do-i-turn-on-logging-or-require-a-reason)).

If your organization uses the [demand plan](/demand-forecasting/demand-plan), edits made there are listed under the plan's own **Edits** button.

## What does each row show?

Where: **Demand** → **Edit Log** → the table.

Each row is one save:

| Column | What it shows |
|--------|---------------|
| **Date** | When the edit was saved |
| **User** | Who saved it |
| **Reason** | The reason typed in the save dialog |
| **SKUs** | The SKUs the save changed |
| **Channels** | The channels the save changed |
| **Edits** | How many cells changed |
| **Qty Impact** | Net change in forecast units (green for an increase) |
| **Rev Impact** | Net change in forecast revenue, where prices are known |
| **Model** | The forecast model that was edited |

## Who changed the forecast for this SKU last week?

Where: **Demand** → **Edit Log** → filter chips → **Date Range** and **SKU**.

1. Set **Date Range** to last week.
2. Add the **SKU** filter and pick the SKU.
3. Read **User**, **Date** and **Reason** on each row. Click a row to see the detail.

Other filters: channel, SKU group, channel and product hierarchy levels, and attributes. The empty state says "No edit logs match your filters" when nothing matches.

## Where can I see the reason someone gave for a forecast change?

Where: **Demand** → **Edit Log** → **Reason** column, or click the row → **Edit Log Detail**.

The **Reason** column shows the reason given at save time. Click any row to open **Edit Log Detail**: the reason, the model and version, the periods, and each **Channel / SKU** changed with its before-to-after change.

## How much did forecast edits change total units this month?

Where: **Demand** → **Edit Log** → **Date Range** = this month → **Qty Impact** and **Rev Impact**.

Filter **Date Range** to this month and read **Qty Impact** on each save (or **Rev Impact** for revenue). To total them, export the log with the export button in the toolbar and sum the column.

## How do I turn on logging or require a reason?

Where: **Settings** → **Forecast Edit Log** (admins).

- **Channel Logging**: choose which channels have **Log Edits** turned on. If logging is off, the Edit Log shows **Edit Logging Disabled** with a link here.
- **User Comment Requirements**: turn **Require Comment** on for users who must give a reason when they save.
- **Override Staleness Thresholds**: the **Drift threshold (%)** and **Absolute floor (units)** that decide when a manual override is flagged as stale (see [Model assignment](/demand-forecasting/model-assignment#stale-override-exceptions)).
