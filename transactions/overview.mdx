# Transactions overview

A transaction (order) is any planned or actual movement of stock: a **purchase** from a supplier, a **transfer** between your locations, a **production** run, or a **sale**. The **Transactions** page lists them all and is where you create, receive and track orders.

## The Transactions page

**Where:** sidebar **Transactions** → **Transactions**.

The sidebar group **Transactions** holds:
- **Transactions**: the order list (this page).
- **Shipments**: containers and other shipments. Only shown if your organization uses shipments. See [Shipments](/transactions/shipments).
- **Review lists**: only shown if your organization uses them. See [Review lists](#what-are-review-lists).

### Header buttons

What you see depends on your account:

| Account | Buttons |
|---|---|
| Most accounts (new order screens) | **Report production**, **Import orders**, **New order** |
| Older accounts | **Create Draft Transaction** |

Buttons only show if you can create transactions. **Report production** also needs permission to receive and fulfill orders. See [Creating orders](/transactions/creating) and [Report production](/transactions/report-production).

### View tabs

| Tab | What it shows | Who sees it |
|---|---|---|
| **Transactions** | One row per order. | Everyone |
| **Drafts** | Orders saved with **Save draft** and not yet applied. | Accounts with the new order screens |
| **Case files** | Groups of orders filed together. See below. | Accounts with the new order screens |
| **Receiving** | Open lines waiting for stock, to receive against. See [Receiving](/transactions/receiving). | Users who can receive orders |
| **Line Items** | One row per order line: SKU, quantity, source, destination, dates. | Everyone |
| **Timeline** | Quantities arriving (or leaving) over time, by location or by SKU. | Everyone |

Your organization can hide **Drafts**, **Case files** or **Receiving**. Users who can receive but not create orders see only the **Receiving** tab.

## How do I see only open purchase orders?

**Where:** Transactions → **Transactions** tab → filters **Kind** and **Status**.

1. Set **Kind** to **Purchase**.
2. Set **Status** to **In Progress**. The list starts filtered to **Draft** and **In Progress**; remove **Draft** to see only orders that are open.

**Status** values: **Draft**, **In Progress**, **Received** (everything has arrived), **Completed**, **Archived**.

Other filters:
- **Kind**: **Purchase**, **Transfer**, **Production**, **Sale**.
- **Type**: your organization's own order types, such as "ITR". Only shown if you have any. See [Order types](/transactions/types).
- **Source** and **Destination**: suppliers and locations.
- SKU and SKU group.
- Dates: **Start date**, **Completion date**, **Promised arrival**, **Closed**.

Columns include **Name**, **Reference**, **Internal notes**, **Type**, **Status**, **Source**, **Destination**, **Value** and **Created by**. On accounts with the new order screens you also get **Lines**, **Ordered**, **Received** and **On order**.

## Where do I receive a shipment?

**Where:** Transactions → **Receiving** tab, or the order page → **Report a receipt**.

See [Receiving](/transactions/receiving). If your organization uses shipments, you can also receive a whole container from **Transactions → Shipments**. See [Shipments](/transactions/shipments#how-do-i-receive-a-shipment).

## What's the Timeline view on Transactions?

**Where:** Transactions → **Timeline** tab.

**Timeline** pivots order quantities over time so you can see what lands when. Use the toggle to show rows by location or by SKU. In **Table settings** you can choose:
- **Measure**: **Units** or **Value**.
- **Anchor**: **Arrival** or **Departure**.
- **Granularity**: **Day**, **Week** or **Month**.
- **Group by**, **Filters** and **Export**.

Use **Date range** to set the window.

## What are case files?

**Where:** Transactions → **Case files** tab. Also the **Case file** card on an order's **Overview** tab.

A case file groups orders that belong together, for example a PO and the transfer that moves its goods on. Adding an order to a case file or removing it is filing only. It never moves stock.
- The tab lists **Reference**, **Intent**, **Orders**, **Last computed status** and the opened, closed or archived date.
- Click **Check live** to recompute the status from current stock movements.
- Search with **Search by reference or intent…**.
- An archived case file is kept as a read-only record.

## What are review lists?

**Where:** Transactions → **Review lists**. Only shown if your organization uses them.

A review list is a shared, versioned page of recommendations for your team to look over together. Each list has a **Version** and a **Notes** panel, where you can comment on one recommendation (**This recommendation**) or on the whole review (**This review as a whole**). Use **Filter by tag** to find lists, and **New review list** to start one (give it a **Name** and **Tags**). Tether publishes the versions. If a banner says "This version is newer than the one customers see", you're looking at a draft.

## Opening an order

Click any row to open the order. Most accounts get the order page with **Overview**, **Lines**, **Activity**, **Documents** and **Terms** tabs. Older accounts get the step-based page. See [The order page](/transactions/detail-view).
