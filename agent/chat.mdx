# AI agent chat

The Tether agent is an AI assistant built into the app. Ask it questions, hand it files, and let it carry out multi-step work — you approve every change before it's applied.

<Note>
"Tether Agent" is the default name. Your organization may have renamed it (see [Agent settings](/agent/settings)), so buttons read "Ask Acme Bot" and "Acme Bot is thinking..." (for an agent named Acme Bot). The **Agent** sidebar section needs agent read permission (`agent:read`).
</Note>

For what it can do, see [What the agent can do](/agent/what-the-agent-can-do). Related pages: [Standing reports](/agent/standing-reports), [Memory](/agent/memory), [Agent settings](/agent/settings), [Slack](/agent/slack), [Connect Claude or Grok](/agent/connect-claude-or-grok).

## How do I start a chat?

Where: sidebar header → **New chat**, or **Cmd+K** (Ctrl+K).

- **New chat** — the button at the top of the sidebar. If you're on a live session page, it asks **Start a new chat?**; choose **Start new chat**.
- **Command palette** — press **Cmd+K**, type your question, and choose **Ask Tether Agent:** followed by your question. The chat opens with that question sent. See [Command palette](/tips/command-palette).
- **Chat Sessions** — **Agent → Chat Sessions → New Session**.

## The chat widget

Where: any page, after starting a chat.

The chat opens as a popup in the bottom-right corner. Its header has **Expand to sidebar** / **Collapse to popup** (dock it as a full-height panel on the right), **Open full view** (the full session page) and **Close chat**.

Press Enter to send, Shift+Enter for a new line. While the agent works you'll see "Tether Agent is thinking..." and a stop button. When it needs an approval, a plan decision or a file from you, it shows "Waiting for your response...".

### Attaching files

Click the paperclip (**Attach file**) or drag files onto the chat. You can attach up to 10 files and 50 MB per message, of any type. Pasted images must be PNG, JPEG, WebP or GIF, up to 10 MB each. The agent can also ask you for a file with an upload card.

## Does the agent change data without asking?

No. Before any change, the session shows an **Approval Required** card naming the tool and action, with a preview of what will change and the proposed values in an editable table.

- **Approve** applies it. If you edit a value first, the button reads **Approve with edits**.
- **Reject** blocks it.
- If **Approve** is disabled, the preview can't be applied as it stands — fix the issues the card lists, or reject.

A decided card shows **Approved**, **Rejected**, **Closed unanswered** or **Superseded**.

For bigger pieces of work the agent first proposes a plan in the **Plan** tab, which you approve or send back.

The one exception: if your organization set **Saving memories** to **Save without asking**, the agent saves memories without a card. See [Memory](/agent/memory).

## Where do I see what the agent has done in a session?

Where: **Agent → Chat Sessions → a session** (or **Open full view** from the widget).

The session page shows the chat beside a workspace with these tabs:

| Tab | What's in it |
|-----|--------------|
| **Plan** | A plan the agent proposes for a bigger piece of work, for you to approve or send back |
| **Tasks** | The agent's checklist of steps and their progress |
| **Decisions** | Approvals and file requests waiting on you, with your past decisions under **History** |
| **Files** | Files the agent made for you — exports, reports — to download |
| **Table** | Appears when you open a wide table from the chat |

## Find a past session

Where: **Agent → Chat Sessions**.

The list is grouped by **Today**, **Last 7 days**, **Last 30 days** and **Older**, with columns **Title**, **Status**, **Last active**, **Created by** and **Created**.

- Filter by **Status** (Running, Idle, Needs attention) and **Created by** (My sessions), or search with **Search sessions...**.
- Each row's menu has **Rename**, **Archive** (or **Restore**) and **Delete**. Turn on **Show archived** to see archived chats.
- **Manage Memories** opens the [Memory](/agent/memory) page.

You can also ask the agent: "What did we decide about the Acme PO last week?" — it can search past sessions.

## Can I download a chat?

Where: a session → the download icon (**Export Conversation**).

Choose **Copy as Markdown**, **Download .md** or **Download as HTML**.

## Rate a response

Under an answer, click the thumbs up (**Good response**) or thumbs down (**Bad response**). Click it again to remove your vote.

## Where are session templates?

Session templates no longer exist. To reuse instructions, save them as a [memory](/agent/memory), upload a reference file under [Agent Files](/agent/settings#agent-files), or save a recurring request as a [standing report](/agent/standing-reports).

## How do I make the agent remember our default warehouse?

Tell it ("Remember that our default warehouse is Reno"), or add it yourself on **Agent → Chat Sessions → Manage Memories → Add memory**. See [Memory](/agent/memory).

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| No **Agent** section in the sidebar | Your role lacks agent read permission | Ask an administrator for access |
| The widget switched to the session page | The agent needs an approval, a plan decision or a file | Answer it in the **Decisions** or **Plan** tab |
| Nothing happens after you send | The agent is waiting on you | Check **Decisions** for a pending approval or upload |
| A pasted image was rejected | Only PNG, JPEG, WebP or GIF up to 10 MB can be pasted | Attach it with the paperclip instead |
