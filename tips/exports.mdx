# Exporting data

Tether exports what you see. A table export downloads the rows as the table currently shows them, with your filters applied. There are no separate export screens, scope pickers or field pickers.

## Where is the export button?

**Where:** the **Table Settings** button above a table → **Export CSV**.

<Steps>
  <Step title="Filter the table">
    Set the filters, search and columns you want. The export follows the table as shown.
  </Step>
  <Step title="Open Table Settings">
    Click **Table Settings** at the top of the table. On some tables it's just a sliders icon; hover it to see "Table settings".
  </Step>
  <Step title="Export">
    Click **Export CSV**. The file downloads to your computer.
  </Step>
</Steps>

You can also press `⌘ + K` (`Ctrl + K` on Windows) on any page with an exportable table and choose **Export table to CSV**. If the action isn't offered, that page's table has no export.

## How do I export inventory to Excel?

**Where:** **Inventory** → **Dashboard** → **Inventory** tab → **Table Settings** → **Export to CSV**.

The inventory export is a CSV file, which opens directly in Excel or Google Sheets. It contains the rows and columns currently shown, so set your filters and columns first.

For a history of inventory changes, use the **History** tab's table export the same way.

## Can I download a PO as a PDF?

**Where:** open the order → **Export PDF**, or the order's **Documents** tab → the download button on a document → **PDF**.

Depending on your organization, an order page offers one of these:

- **Export PDF** at the top of the line items, with **By SKU** or **By Collection** layouts. **Export CSV** next to it downloads the line items.
- A **Documents** tab listing the order's documents (such as the purchase order). Click a document's download button and pick **PDF** or **CSV**, or click **View** to preview it.

If your organization has more than one template for that kind of document, the menu also lets you pick the **Template**; the default is marked "(default)". What appears on the PDF (fields, columns, your logo and addresses) is set by an Admin in **Settings** → **General** → **Documents**. See [How do I change what's on our PO PDF?](/administration/settings-reference#how-do-i-change-whats-on-our-po-pdf)

## Can I export an order's size run to Excel?

**Where:** open the order → **Lines** tab → **Export**.

On orders with a **Lines** tab, **Export** offers **CSV** or **Excel (.xlsx)**. It exports saved values only: if you have unsaved line edits, save them first. If you've searched the lines, only matching rows are exported.

## Other exports

| What | Where |
|------|-------|
| Planning tables (Transfer, Production, Purchase, MRP) | **Table Settings** → **Export CSV** |
| Season Plan | **Table Settings** → **Export CSV** |
| Setup & Health issues | the **Download CSV** button on an issue in **Settings** → **Setup & Health** |
| A pick list for a sales order | **Print pick list** on the order (prints rather than downloading a file) |

## Can I export through the agent or an API?

The agent can read and summarize data for you in chat; ask it, for example, "List SKUs with under 2 weeks of cover". For automated exports into your own systems, an Admin can create an API key in **Settings** → **Integrations** → **API Keys**, or connect BigQuery if Tether has set it up for you.
