# Command palette (search)

The command palette is Tether's search box. It finds pages, records and actions, and hands anything else to the agent.

## How do I open search?

**Where:** press `⌘ + K` (Mac) or `Ctrl + K` (Windows), or click **Search** (magnifying glass) at the top of the sidebar.

Type in the **Search or navigate...** box, use the arrow keys to move, and press `Enter` to open. `Escape` closes it.

## What can I search for?

**Where:** `⌘ + K` → type.

Results are grouped:

| Group | What it holds |
|-------|---------------|
| **Recent** | Pages and records you opened recently |
| **Pages** | Every sidebar and Settings page your role can open, under your organization's names, plus **Location Groups**, which isn't in the sidebar |
| **Actions** | **Export table to CSV**, **Show Keyboard Shortcuts**, **Switch to Dark Mode** / **Switch to Light Mode** |
| **Color Themes** | Switch the app's color theme (type "theme") |
| **SKUs** | SKUs by code or name |
| **Collections** | Collections (older catalog) |
| **Transactions** | Orders by reference number or name |
| **Sales Orders** | Sales orders by order number |
| **Warehouses**, **Suppliers** | Warehouses and suppliers by code |
| *Your agent's name* | **Ask** *agent*: *what you typed* |

Pages match on their title and on common words: typing "po" or "buy" finds **Purchase**, "integration" finds **Data Ingestion** (plus API Keys and MCP), and "command center" still finds **Overview**.

## Can I search for a sales order number?

**Where:** `⌘ + K` → type the order number → **Sales Orders** group.

Type the order number (or part of it). Matching orders appear under **Sales Orders**; press `Enter` to open one. Purchase orders, transfers and other orders appear under **Transactions** by their reference number.

## How do I export this table?

**Where:** `⌘ + K` → **Export table to CSV**.

On a page with an exportable table, open the palette and choose **Export table to CSV** (it's listed under **Actions**, or type "export" or "csv"). It downloads the table as it's currently filtered, the same as **Table Settings** → **Export CSV**. See [Exporting data](/tips/exports).

## How do I ask the agent from the search bar?

**Where:** `⌘ + K` → type a question → **Ask** *agent name*.

Type your question, for example "which SKUs stock out next month", and choose the last item, **Ask** *agent name*: *your question*. The agent chat opens with your question already sent as a new conversation. See [Agent chat](/agent/chat).

## Change the look

Type "dark" or "light" to switch mode, or "theme" to list color themes. You can also switch mode from the **Tether** workspace menu, and themes in **Settings** → **Theme**.

## Keyboard shortcuts

Type "shortcuts" and choose **Show Keyboard Shortcuts**, or press `⌘ + /`. See [Keyboard shortcuts](/tips/shortcuts).
