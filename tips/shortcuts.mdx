# Keyboard shortcuts

## Is there a keyboard shortcut list?

**Where:** press `⌘ + /` or `⌘ + ?` (`Ctrl + /` on Windows), or open search with `⌘ + K` and choose **Show Keyboard Shortcuts**.

The list opens in a dialog and matches the table below. On Windows, use `Ctrl` wherever this page says `⌘`.

## All shortcuts

| Keys | What it does |
|------|--------------|
| **Navigation** | |
| `⌘ + K` | Open the command palette (search) |
| `⌘ + /` or `⌘ + ?` | Show keyboard shortcuts |
| `Escape` | Close a modal or dialog |
| **Actions** | |
| `⌘ + S` | Save the current form (when editing) |
| `⌘ + Enter` | Submit a form |
| **Editing** | |
| `Enter` | Confirm an inline edit |
| `Escape` | Cancel an inline edit |
| `Tab` / `Shift + Tab` | Move to the next / previous field |
| **Tables** | |
| `↑` `↓` | Move between rows |
| `←` `→` | Move between columns |
| `Enter` | Open the selected row |
| `⌘ + F` | Focus the table's search |
| **Agent chat** | |
| `/` | Focus the message box |
| `Esc` | Stop the agent while it's answering, or leave the message box |

## How do I focus the agent chat with the keyboard?

**Where:** an open agent chat.

Press `/` to jump to the message box and start typing. Press `Esc` to stop the agent mid-answer, or to leave the message box. To start a new chat from anywhere, open search with `⌘ + K`, type your question and choose **Ask** *agent name*. See [Command palette](/tips/command-palette).
