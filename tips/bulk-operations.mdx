# Bulk actions

Tether has no single bulk-edit mode. Each page that supports changing many things at once has its own control, listed here.

## Can I update many inventory counts at once?

**Where:** **Inventory** → **Dashboard** → **Inventory** tab → **Table Settings** → **Edit quantities**, or **Upload Inventory**.

- **Edit quantities**: turn it on in **Table Settings**, type counts into the **On Hand** column for as many rows as you need, and submit them together. If your organization uses adjustment approval, they go to an approver; approvers' own changes apply at once.
- **Upload Inventory**: the button at the top of the page opens **Upload Inventory Data**. Upload a CSV (there's a template to download), give a **Reason for Upload**, and Tether applies the quantities. This button is hidden for roles that can't change stock directly and for the stock-counting view.
- **Counts** tab: run a physical count across many SKUs and post it in one go (organizations using the movement ledger).

See [Inventory adjustments](/inventory/adjustments).

## How do I mark many orders as shipped?

**Where:** **Sales** → **Orders** → tick the orders → **Mark shipped**.

Tick the Shopify orders you've shipped in the order list. A bar appears beneath the list with **Mark shipped (*n*)**. Give one reason for all of them and confirm. Tether answers each order on its own and lists any it couldn't mark, with why. A single order also has its own **Mark shipped** button.

## Can I import orders from a CSV or spreadsheet?

**Where:** **New chat** → attach the spreadsheet → ask the agent to import it.

For a spreadsheet of purchase orders, attach it in agent chat and ask, for example, "Import these POs". The agent reads every row, groups lines by the PO-number column, asks which statuses or warehouses to include if that's unclear, and shows you a preview of which POs are ready, already imported, or failing (with the reason) before anything is saved.

**Transactions** → **Import orders** is a different tool: it takes a single order document in JSON format (as produced by an integration) and previews the change before you apply it. It's available on organizations using the movement ledger.

## Can I edit many order lines at once?

**Where:** open an order → **Lines** tab.

Edit as many lines as you like. Unsaved changes are counted on the **Lines** tab badge, and you save them together.

## How do I create many SKUs at once?

**Where:** **Products** → **SKU Groups** → a SKU group → **Bulk Create SKUs**.

Creates every variant of the group (for example, every size and color) in one step. You can also ask the agent to create SKUs from a spreadsheet.

## Lots

**Where:** **Inventory** → **Lots**.

- **Assign lots (*n*)**: assigns lots to all stock that has no lot yet, in one dialog.
- **Reallocate lot**: moves a lot's quantities across positions in one step.

## Many safety stock or replenishment values at once

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **Replenishment Settings** (older organizations).

Select rows and apply one value with the bulk fields. On organizations using Locations, set a policy once on a location or SKU group instead. See [Inventory & Forecast settings](/administration/inventory-settings).

## Download many rows

Every table exports what it shows with **Table Settings** → **Export CSV**. See [Exporting data](/tips/exports).
