# Inventory & Forecast settings

**Inventory & Forecast** is a Settings page for organizations that haven't moved to **Locations** yet. It holds per-warehouse inventory settings and channel set-up in six tabs. On organizations that use Locations, the same settings live on locations and policies instead, and these tabs disappear one by one as each part moves.

## Why don't I see Inventory & Forecast in Settings?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast**.

You won't see it when:

- **Your organization uses Locations.** Once locations, suppliers and channels have all moved to **Supply Chain** → **Locations**, the only tab left would be **Fulfillment Mappings**, so the whole entry is hidden. Set things up on locations and in **Supply Chain** → **Policies** instead (see the table below).
- **Your role can't open it.** Ask an Admin.

| Tab | Shown until your organization moves… | Where it lives afterwards |
|-----|--------------------------------------|---------------------------|
| **Replenishment Settings** | warehouses to Locations | **Supply Chain** → **Locations** and **Policies** |
| **SKU Warehouse Assignments** | warehouses to Locations | **Supply Chain** → **Locations** and **Policies** |
| **Channel Availability** | channels to Locations | the channel location's **Sales** tab |
| **Channel Pricing** | channels to Locations | the channel location's **Sales** tab |
| **Fulfillment Mappings** | (always shown while the page is) | — |
| **Supplier Capabilities** | suppliers to Locations | the supplier location, and **Policies** |

## Where do I set safety stock?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **Replenishment Settings** (older organizations). Organizations on Locations: **Supply Chain** → **Policies**.

<Steps>
  <Step title="Pick a warehouse">
    On **Replenishment Settings**, choose the warehouse in **Select Warehouse**. The table lists that warehouse's SKUs.
  </Step>
  <Step title="Enter safety stock in days">
    Edit **Safety Stock (days)** for a SKU, and if needed **Max days** (must be more than safety stock) and **Replenishment Cadence** (**Weekly**, **Monthly**, **Quarterly**, **Custom Days**, or **None (Clear)**), and the **Source Warehouse** it's replenished from.
  </Step>
  <Step title="Or set many at once">
    Select several rows and use the bulk fields (such as **Safety Stock**) to apply one value to all of them.
  </Step>
</Steps>

On organizations that use Locations, safety stock is a policy: set it in **Supply Chain** → **Policies**, or on a location. See [Policies](/supply-planning/overview).

## Which SKUs are stocked at which warehouse?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **SKU Warehouse Assignments**.

Choose a warehouse, then assign or unassign SKUs. Filter by **SKU Type** (Finished Good, Component, Variant, Kit, Bundle), **Status**, and **Assigned Only** / **Unassigned Only**.

## Where do I map a channel to a warehouse?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **Fulfillment Mappings**.

Fulfillment mappings say which warehouse ships each channel's orders. Set a default warehouse, then set a warehouse per channel (and per SKU where it differs) with **Set warehouse...**. The table shows **Channel**, **SKU**, **Warehouse**, **Updated** and **Updated By**.

## Which SKUs are sold on which channel?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **Channel Availability**.

A grid of SKUs against channels. Turn a SKU on or off for a channel. Sales Reps can usually edit this tab.

## Where do I set channel prices?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **Channel Pricing**.

Use the filters to pick SKUs and channels, then edit the price for each SKU-channel pair.

## Where do I set a supplier's lead time and MOQ?

**Where:** **Settings** → **Forecasting** → **Inventory & Forecast** → **Supplier Capabilities** (older organizations). Organizations on Locations: the supplier's location and **Supply Chain** → **Policies**.

Pick a supplier and edit **Lead Time** (days) and **MOQ** (quantity) per SKU.

<Note>
  Inventory health rules, overstock thresholds and default lead times aren't set on this page. Lead times between locations are in [Lead times](/inventory/warehouses/lead-times) (older organizations) or Policies.
</Note>
