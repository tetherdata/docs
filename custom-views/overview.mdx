# Custom views

A custom view is a page built for your organization — for example a policy-exceptions list, a buying planner, or a report that replaces a spreadsheet you used to keep. Tether builds them; they show your live Tether data.

## Where are our custom views?

Where: **Inventory → Custom views** (`/custom-views`).

- The **Custom views** page lists every view in your organization with its name, comments and version. Search with **Search views**.
- A view can also be placed in any sidebar section — for example your **Policy exceptions** view may sit under **Supply Chain**. Look there, or press **Cmd+K** and type its name.
- A view shows in the sidebar only once it has a live version.

<Note>
You need custom views read permission (`custom_views:read`). Without it the page shows "not found". If the page says "Custom views aren't set up for this organization", ask Tether.
</Note>

## Can I edit values in a custom view?

Only if that view was built to allow it. Some views let you change values or take actions; each view's own buttons say how. Any change runs with **your** permissions, so you can't change something in a view that you couldn't change elsewhere in Tether.

If you see "This view has changed since it was shown. Reload the page to use it.", reload and try again.

## Archived views

People with custom views write permission (`custom_views:write`) can click **Show archived views** on the **Custom views** page to see retired views.

## How do I get a custom view built or changed?

Ask Tether. Send the sheet or report you use today and what you want it to show. Tether builds the view, and editors choose where it appears in the sidebar with **Show in nav**.
